# 专注时光 (FocusTime) - 学习时间记录

一个极简、优雅、高自律感的沉浸式学习时间记录与管理工具。支持纯本地运行与 PWA 手机/平板免安装使用。

---

## 🌟 核心功能一览

### 1. ⏱️ 双模式计时引擎
* **正向自由模式**：自由学习，想学多久学多久，中途随心暂停/继续，学完打卡。
* **番茄工作法模式**：预设 25分钟专注、45分钟长专注、5分钟短休、15分钟长休，带剩余进度条。
* **防丢失自动补时**：哪怕误关网页或刷新页面，重新打开会自动补齐并恢复计时进度。

### 2. 🌱 学习打卡热力图 (GitHub 风格绿格子)
* **近 16 周打卡墙**：每天的努力一目了然，学得越久方块越绿。
* **🔥 连续打卡追踪 (Streak)**：实时统计当前连续打卡天数与历史最高连续天数，激励每日坚持。

### 3. 🎯 今日学习目标进度
* 顶部直观展示 **今日已学 / 每日目标** 动态渐变进度条。
* 点击“修改目标”可自由调整每日目标时长（如 4 小时、6 小时）。达成时自动点亮成就徽章！

### 4. ➕ 手动补记时长
* 针对在图书馆、自习室学习忘开网页的场景，点击 **“手动补记”** 即可直接选择日期、学科、时长补录数据。

### 5. 🎧 原生算法白噪音伴奏
* **零外部音频文件加载**，纯浏览器 Web Audio 原生实时数学算法合成：
  * 🌧️ 细雨微濛
  * 🌊 慢潮海浪
  * 🔥 温暖篝火（带随机劈啪木柴声）
  * ☕ 深度褐噪（专注降噪专属）
  * 🔔 禅意西藏颂钵打卡音
* 附带音量拖拽调节与跳动声波指示。

### 6. 📱 手机端 PWA 秒变独立 App
* 支持渐进式 Web 应用规范（PWA）。
* **手机/iPad 添加方式**：
  * **iPhone / iPad (Safari)**：点击浏览器底部的“分享”按钮 ➡️ 选择 **“添加到主屏幕”**。
  * **Android (Chrome / 常见浏览器)**：点击右上角菜单 ➡️ 选择 **“添加到主屏幕”** 或 **“安装应用”**。
  * 添加后桌面会出现专属 App 图标，打开无浏览器地址栏，沉浸全屏体验！

### 7. 🏷️ 标签页标题实时联动
* 切换到其他标签页查资料或背单词时，标签页标题会动态显示：
  * `(01:23:45) ⏱️ 💻 编程开发 · 专注时光`
  * 余光就能看到计时进度，杜绝摸鱼。

### 8. 💾 数据备份与恢复闭环
* 纯本地存储在浏览器本地（LocalStorage），保护个人学习隐私。
* 支持一键 **“导出备份”**（JSON 文件）以及 **“导入备份”**（换新电脑或手机时一键迁移）。
